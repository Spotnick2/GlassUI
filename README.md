# Glass UI

The rest of **World of Warcraft: Forever**'s interface, in liquid glass.

It's a reskin: Blizzard's windows keep working exactly as before. Glass UI only changes how they
look, and every window's skin can be turned off on its own.

- **Glass windows:** the merchant, popups, the character sheet and the world map first, then bags,
  tooltips, menus, the Escape menu, the auction house, professions, the group finder, the spellbook
  and talents, the guild and friends windows, the damage meter and the cooldown manager.
- **Steps aside** for any Glass addon that owns a window (Glass Mail owns the mail window).
- **One home for the Glass family**, if you use other Glass addons: their settings under one
  "Glass UI" entry, and one page listing them. Every Glass addon still works without Glass UI.

Status: in development. The plan is [docs/PLAN.md](docs/PLAN.md).
